# Paper-to-artifact mapping

Main-figure numbers follow the current manuscript after removal of the old conceptual Figure 2.

| Paper item | Released evidence / code |
|---|---|
| Figure 1: study overview | `docs/figures/study_overview.png` |
| Figure 2: data protocol | `docs/figures/data_protocol.png`; `data/manifests/`, `data/context_indices.zip`, `configs/` |
| Figure 3: recognition/acceptance framework | `docs/figures/recognition_framework.png`; `src/tcmp_repro/learner.py`, `evaluation.py` |
| Figure 4: contamination gradients | `scripts/analyze_results.py`; `results/reference/{tcmp,indian}/results/`; generated `01_contamination_gradients` |
| Figure 5: component ablations | Same inputs, generated `02_component_ablation` |
| Figure 6: acceptance tradeoffs | Same inputs, generated `03_rejection_tradeoffs` |
| Table 1: original pool rules | `configs/original_formal.json`; `src/tcmp_repro/original_experiment.py` |
| Table 2: closed recognition | `scripts/analyze_formal.py` for TCMP; Indian closed entries in `derived_statistics.json` |
| Table 3: 0–50% losses | Fixed-known gradient entries in `derived_statistics.json` |
| Table 4: acceptance at 50% | `gate_comparisons/0.5` in the same statistics JSON |
| Fixed-total, class-tail, pseudo-label and Indian sixteen-shot summaries | Full reference contexts, generated CSV/statistics and plots 04–06 |
| Original open-pool recognition | 476 formal result JSONs, `scripts/analyze_formal.py`, original runner |
| Pool-seen/query-only unknowns and retrospective curves | Group metrics in each context; archived original `results/reference/formal/curve_records.json` |
| Review-stage neighbor/shared-gate controls | `results/reference/review/`, including per-setting JSONs and recorded summaries; original control source in `provenance/review_reference/` |

The current dual-source runner regenerates all seven classifier / three gate controls. Historical review 1NN/3NN controls are retained as source/records; their old server orchestration is not a separate portable one-command target. Original probability arrays are regenerated by the original runner, rather than supplied as multi-gigabyte caches. Full-image representative illustrations can be reconstructed from the public dataset using manifest paths/hashes; no raw photographs are bundled apart from the attributed overview/framework figure examples.
